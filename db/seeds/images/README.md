# seed用の写真

ここに次の名前で写真を置くと、`bin/rails db:seed` のときに自動で添付されます。
ファイルがなくてもエラーにはなりません（NO IMAGE のままになります）。

| ファイル名 | 付く先 |
|---|---|
| oil.jpg | エンジンオイル交換（DIY） |
| tire.jpg | スタッドレスタイヤへ交換 |
| battery.jpg | バッテリー交換 |
| wiper.jpg | ワイパーゴム交換 |
| air_filter.jpg | エアフィルター交換 |
| wash.jpg | 手洗い洗車とコーティング |
| prius.jpg | demoユーザーの車（プリウス） |
| fit.jpg | ゲストの車（フィット） |

横1200pxくらい・1枚300KB以下にしておくと、リポジトリが重くなりません。
ナンバープレートや人の顔が写っている写真は避けてください。
